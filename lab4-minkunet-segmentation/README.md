# Lab 4: Sparse Convolutional LiDAR Segmentation with MinkUNet

Semantic segmentation of LiDAR point clouds using MinkUNet, a sparse convolutional network operating directly on the SemanticPOSS dataset. Implemented in Python, trained on Google Colab.

Course: 3D Data Processing, University of Padova.
